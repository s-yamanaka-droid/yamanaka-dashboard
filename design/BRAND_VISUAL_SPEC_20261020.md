# Lakkan Brand / visual implementation

- Primary job: 初めて訪れた人がLakkanのブランドを見て、制作事例・Racco・Recordsへ進む。
- DESIGN_VARIANCE: 75
- MOTION_INTENSITY: 25
- VISUAL_DENSITY: 40
- Basis: 本人が承認したキーアートと既存A3ロゴ、名刺・Racco原本。
- Palette: natural paper #F6F2E9 / vermilion #B63328 / ink #171713 / warm grey #EAE4D8。
- Type: Shippori Minchoは大見出し、Noto Sans JPは本文、Geist Monoは小見出し。ロゴはA3の原画。
- Layout: 左38%の文字面、右62%の4:3物撮り。スマートフォンは文字・写真・ギャラリーの順。
- Signature: コットン紙とレコードに同じロゴが現れる朱赤の静物。
- Motion: 入場時に写真が短く収まり、ギャラリーのレコードが回る。Racco・名刺はhoverに応答。reduced-motionはすべて停止。
- Sources: 既存のLakkanLogo、Raccoの公開アバター、Now on AIrの公開記事画像。物撮りは承認カンプを参照しbuilt-in image_genで新規生成、WebPへ変換。新たな外部UIコードは追加していない。
- Must keep: 名刺表とヘッダーは英字のみ。Raccoのブランドブックを別入口から開ける。サイト全体の音楽プレイヤーとRecordsを維持。
- Avoid: ページ全体の縮小スクリーンショット、印刷操作を第一の入口にすること、ロゴの打ち直し。

物撮りの指示: 朱赤の布、自然白の名刺2枚とレコードジャケット、黒いレコード。名刺は英字のみ、ジャケットには小さな縦の楽観。画面UIや個人連絡先は描かない。
生成画像内の印刷は展開イメージ。Webの実ロゴには原本を使用する。実商品・印刷入稿の完成を示さない。
