# Racco services edition

The corporate services now describe four ways to change work and business: work redesign and AI; connected systems and apps; words, Web experiences, inquiry paths and continued updates; roles, recruiting and people support.

## Experience

- One paper-tab service chooser replaces the duplicate lists.
- Original Racco portraits accompany the company story and consultation actions. The guide responds with a short remark when selected.
- Real HTML text and original SVG diagrams explain work changes as examples, without invented client results or metrics.
- The selected topic follows into the existing email-draft inquiry form.
- A homepage section, consultation tickets and footer continue the same visual direction.
- The poster hero, original crowd, company facts, public works and current brand book are retained.

## Verification

`npm run check:release` covers typecheck, lint, existing brand/inquiry tests, public-data validation, production build and route/asset smoke checks. Browser review covers 375, 768, 1024 and 1440px, all four services, legacy `#product` links, keyboard navigation, detail disclosure and inquiry context. Reduced motion disables the newly added transitions and panel entrance animation.

The character images remain original assets. CSS compositing blends their white backgrounds into the paper; the source files are unchanged. The diagrams are illustrative examples, not measured outcomes. Inquiry controls create or copy a draft; they do not send messages from this website.
